# @docsgraph/ui

Shared React component library for docsgraph's web and desktop clients.

Components are consumed directly as TypeScript source (no build step) via
pnpm workspace linking — `main`/`types` point at `src/index.ts`.

## Tailwind CSS

This package does **not** ship its own Tailwind config or compiled CSS.
Components use Tailwind utility classes in their `className`s, but the
actual CSS is generated by whichever app consumes them. Each app
(`apps/web`, `apps/desktop`) owns a `tailwind.config.ts` whose `content`
glob includes `../../packages/*/src/**/*.{ts,tsx}` so Tailwind's scanner
picks up class names used here.

Rationale: Tailwind's JIT scanner needs a single source of truth for the
design tokens (theme, plugins) and a single generated stylesheet per
shipped app. Centralizing config in each app avoids double-generating CSS
or having to sync a shared config into every consumer.
